## 🚀 Featured Projects

Some of the practical projects included in this repository:

### 🤖 Restaurant AI Agent
An AI-powered restaurant assistant built using Python, LangChain, and Groq. It can search restaurants, estimate dining costs, maintain conversation context, and apply input validation and privacy guardrails.

### 🧠 Local Hugging Face RAG
A local Retrieval-Augmented Generation project that explores document retrieval and answering questions using locally hosted Hugging Face models.

### 🔐 Authentication & Protected Routes
A React-based exercise exploring authentication concepts and protected application routes.

## 💻 Running the Projects

Each project may have its own dependencies and setup instructions.

For a typical Python project:

```bash
# Clone the repository
git clone https://github.com/Mradull/EY_training.git

# Open the project folder
cd EY_training

# Navigate to the required project
cd 06th_NOV/Restaurant_AI_Agent

# Install dependencies
pip install -r requirements.txt

# Run the application
python agent.py
```

For React projects, navigate to the relevant project directory and follow its `README.md` or package configuration.
